## T0 前置实测（动工前定默认值）

| 项 | 结论 | 对设计的影响 |
|---|---|---|
| PrintWindow(flags=0) 对 GPU 窗口 | Chrome 得**白图**（客户区空，但整图 contrast 仍 35 会骗过整图黑帧检测） | 降级链只用 PW_RENDERFULLCONTENT；黑帧检测**必须裁客户区单独算** |
| PrintWindow(PW_RENDERFULLCONTENT) | 前台 Chrome/Notepad/Electron/UWP 均出**真内容**，16–66ms | 作为首选后端 |
| windows-capture (WGC) | 可出真内容，单帧 176–280ms；本机 `draw_border=False` **抛异常**，必须传 `None` | 作为后台兜底；已据此修正调用 |
| WinRT OCR 中文 | 原生分辨率识别率低（"截图插件"→"截条适件"）；**放大 2x 后 4/5 关键串命中** | OCR 前对小图默认放大 |
| UIA 文本读取 | Notepad 编辑区精确读出（含已知串"永不静默失败"） | `read_text` 默认 UIA 优先 |
| UIA IsPassword | WinForms 密码框**可靠识别**（值读出为空，天然脱敏）；tkinter `show='*'` 不上报 | 密码遮罩用 WinForms 类控件，tkinter 限制已记录 |
| 图像返回通道 | path 与 inline 两种均跑通；path 默认（Claude 用 Read 读图最省上下文） | `return_mode` 默认 `path` |

## 端到端像素核验

通过真实 MCP 工具截 WinForms 登录窗，人工 Read 两版对比：
- 不打码版：用户名 `alice@example.com` 可见，密码字段存在；
- `mask_passwords=true` 版：密码字段**整条涂黑**，用户名保留。
→ 密码遮罩按预期工作（`password_fields_masked: 1`）。
